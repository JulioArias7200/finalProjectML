# Evidencias de aceptación

Depositar aquí informes de pruebas, tablas agregadas, capturas y actas. Usar nombres como `T08_cobertura_2026-10-02.md`. Cada informe debe indicar tarea, criterio Axx, fecha, `run_id`, entradas/hash, método/comando, resultado esperado, resultado observado, conclusión y revisor. Omitir identificadores empresariales, microdatos y secretos. La ruta relativa desde la raíz se coloca en `seguimiento.csv`.

La existencia del archivo no basta: el revisor debe leerlo y registrar `reviewer` y `reviewed_at`. Una prueba fallida queda como evidencia de trabajo, sin cambiar la tarea a `completado`.
